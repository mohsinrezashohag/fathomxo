# FathomXO

The FathomXO company website: an agency/marketing site with services, projects,
team, blog, pricing, FAQ, and contact pages. Built with Next.js (App Router),
React, TypeScript, and Tailwind CSS v4.

## Commands

Uses **Bun** as the package manager.

- `bun install` - install dependencies
- `bun run dev` - dev server at http://localhost:3000
- `bun run build` - production build
- `bun run start` - production server
- `bun run lint` - lint
- `bunx prettier --write .` - format
